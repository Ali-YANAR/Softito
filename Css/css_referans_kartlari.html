CSS Özellikleri Referans Rehberi

Tüm dosyalardan derlenen benzersiz CSS özellikleri — açıklamalı ve değerleriyle

Kutu Modeli
margin
Elemanın dış boşluğunu ayarlar — çevre elemanlarla mesafe.
Kullanılan: 0, 30px, 20px, 8px, 40px
Varsayılan: 0 — negatif değer alabilir
padding
Elemanın iç boşluğunu ayarlar — içerik ile kenarlık arasındaki mesafe.
Kullanılan: 8px, 14px 16px, 20px, 60px
Varsayılan: 0
box-sizing
Genişlik/yükseklik hesabına padding ve border'ın dahil edilip edilmeyeceğini belirler.
Kullanılan: border-box
Varsayılan: content-box
width
Elemanın yatay genişliğini belirler.
Kullanılan: 100%, 300px, 380px
Varsayılan: auto
max-width
Elemanın alabileceği en fazla genişliği sınırlar.
Kullanılan: 100%, 380px, 460px, 1400px
Varsayılan: none (sınırsız)
min-height
Elemanın alabileceği en küçük yüksekliği belirler.
Kullanılan: 100vh
Varsayılan: auto (0 kabul edilir)
height
Elemanın dikey yüksekliğini belirler.
Kullanılan: 100%, 100vh, 300px
Varsayılan: auto
Yerleşim (Layout)
display
Elemanın görüntülenme modelini belirler — blok, satır içi, flex, grid gibi.
Kullanılan: flex, grid, block, none
Varsayılan: etikete göre değişir
flex
Flex öğesinin büyüme, küçülme ve temel boyutunu tek satırda tanımlar.
Kullanılan: 1, 1.2
Varsayılan: 0 1 auto
flex-direction
Flex öğelerinin dizilme yönünü belirler — yatay veya dikey.
Kullanılan: row, column
Varsayılan: row
flex-wrap
Flex öğeleri sığmadığında alt satıra geçip geçmeyeceğini belirler.
Kullanılan: wrap
Varsayılan: nowrap
flex-shrink
Flex öğesinin konteynır daraldığında küçülmesini engeller.
Kullanılan: shrink-0 → flex-shrink: 0
Varsayılan: 1
justify-content
Flex/grid öğelerini ana eksen üzerinde hizalar.
Kullanılan: center, space-between
Varsayılan: flex-start
align-items
Flex/grid öğelerini çapraz eksen üzerinde hizalar.
Kullanılan: center, stretch, start
Varsayılan: stretch
gap
Grid veya flex öğeleri arasındaki boşluğu ayarlar.
Kullanılan: 8px, 12px, 16px, 30px, 40px
Varsayılan: 0
order
Flex öğesinin kaynak sırasından bağımsız olarak görsel sırasını değiştirir.
Kullanılan: order-first → order: -9999
Varsayılan: 0
grid-template-columns
Grid düzeninde sütunların genişliklerini ve sayısını tanımlar.
Kullanılan: repeat(auto-fit, minmax(340px, 1fr))
Varsayılan: none
position
Elemanın konumlandırma yöntemini belirler.
Kullanılan: static, relative, absolute, fixed, sticky
Varsayılan: static
top / left / right / bottom
Konumlandırılmış öğenin kenar uzaklıklarını ayarlar.
Kullanılan: 20%, 15%, 10%
Varsayılan: auto
z-index
Üst üste gelen öğelerin öncelik sırasını belirler — büyük değer öndedir.
Kullanılan: 2, 10, 20
Varsayılan: auto
overflow
İçeriğin taşması durumunda ne yapılacağını belirler.
Kullanılan: hidden, auto
Varsayılan: visible
Renk & Arka Plan
background-color
Elemanın arka plan rengini düz renk olarak ayarlar.
Kullanılan: #28a745, #0b0e14, #02c076, #f8fafc
Varsayılan: transparent
background (degrade)
Arka plan için kısayol; renk, degrade veya resim tanımlar.
Kullanılan: linear-gradient(135deg,...)
radial-gradient(circle,...)
Varsayılan: transparent
color
Metnin ön plan (yazı) rengini belirler.
Kullanılan: white, #848e9c, #0f172a, #64748b
Varsayılan: tarayıcı teması (siyah)
Yazı Tipi & Metin
font-family
Kullanılacak yazı tipi ailesini belirler.
Kullanılan: Arial, 'Segoe UI', Consolas, monospace
Varsayılan: tarayıcı fontu
font-size
Metnin boyutunu ayarlar. Tailwind skalası veya doğrudan değer kullanılabilir.
Kullanılan: text-xs (0.75rem) → text-2xl (1.5rem)
Özel: [8px], [10px] — Varsayılan: 1rem
font-size: clamp()
Min, ideal ve max boyutu viewport genişliğine göre akıcı ölçekler.
Kullanılan: clamp(2.2rem, 6vw, 3.2rem)
Sözdizimi: clamp(min, tercih, max)
font-weight
Metnin kalınlığını belirler.
400 = normal, 700 = bold, 800 = extrabold, 900 = black
Varsayılan: 400
line-height
Satırlar arası dikey boşluğu ayarlar.
Kullanılan: 1.2, 1.6, 1.7
Tailwind: leading-tight(1.25) → leading-loose(2)
Varsayılan: normal (≈1.2)
letter-spacing (tracking)
Harfler arasındaki yatay mesafeyi ayarlar. Tailwind'de "tracking" adıyla kullanılır.
tracking-tighter: -0.05em
tracking-tight: -0.03em
tracking-normal: 0em
tracking-wide: 0.05em
tracking-wider: 0.1em
tracking-widest: 0.25em
Varsayılan: normal (0)
text-transform
Metnin büyük/küçük harf dönüşümünü belirler; etiket ve rozetlerde sık kullanılır.
Kullanılan: uppercase
Seçenekler: uppercase, lowercase, capitalize, none
text-align
Metnin yatay hizalamasını belirler.
Kullanılan: center, left
Varsayılan: left
white-space
Boşluk ve satır kırma davranışını kontrol eder; kod blokları için kullanılır.
Kullanılan: pre-wrap
Varsayılan: normal
Kenarlık & Köşe
border
Kenarlık kalınlığını, stilini ve rengini kısayol ile tanımlar.
Kullanılan: 1px solid #ccc, none
Varsayılan: medium none currentColor
border-top / right / bottom
Yalnızca belirtilen kenara kenarlık uygular.
Kullanılan: border-top: 6px solid #3b82f6
border-bottom: 3px solid #cbd5e1
border-radius
Köşeleri yuvarlar. Tailwind skalası: rounded-sm → rounded-full.
Kullanılan: 4px, 8px, 12px, 16px
rounded-full = 9999px
Varsayılan: 0
box-shadow
Elemana gölge veya dış çerçeve ekler.
Manuel: 0 4px 6px rgba(0,0,0,0.05)
Tailwind: shadow-sm, shadow-md, shadow-lg
Varsayılan: none
border-collapse
Tablo kenarlıklarının birleşip birleşmeyeceğini belirler.
Kullanılan: collapse
Varsayılan: separate
outline
Elemanın dışına layout'u etkilemeden çizgi çizer; focus için kullanılır.
Kullanılan: none (kaldırıldı)
Varsayılan: tarayıcı tanımlı
Etkileşim & Animasyon
cursor
Fare imlecinin şeklini belirler.
Kullanılan: pointer
Varsayılan: auto
transition
Özellik değişimlerini belirtilen süre ve hızlanma eğrisiyle canlandırır.
Kullanılan: all 0.3s ease
background-color 0.2s ease
Tailwind: transition-colors duration-300
transform
Döndürme, ölçekleme, taşıma gibi 2D/3D dönüşümler uygular.
Kullanılan: scale(0.98), translateY(-5px)
Varsayılan: none
animation / @keyframes
Tanımlanmış animasyonu bir elemana bağlar ve çalıştırır.
Kullanılan: pop 0.4s ease
@keyframes ile birlikte kullanılır
Varsayılan: none
Responsive
@media screen
Belirli ekran genişliklerinde farklı CSS kuralları uygulamak için medya sorgusu tanımlar.
max-width: 600px → mobil
min-width: 768px → tablet
min-width: 992px → masaüstü
min-width: 1200px → geniş ekran
Tailwind breakpoint öneki
Belirli ekran genişliğinin üstünde CSS sınıfını aktive eder.
Kullanılan: hidden md:flex, md:hidden
sm:grid-cols-2, md:grid-cols-3
sm≥640px, md≥768px, lg≥1024px
Diğer
filter
Elemana grafik filtreler uygular — bulanıklaştırma gibi.
Kullanılan: blur(30px), blur(40px)
Varsayılan: none
content
::before / ::after pseudo-öğelerine içerik ekler.
Kullanılan: '' (boş string)
Pseudo-öğe için zorunludur
-webkit-background-clip
Arka planın hangi alana uygulanacağını belirler; degrade metin efekti için kullanılır.
Kullanılan: text
Varsayılan: border-box
list-style-type
Sırasız listelerdeki madde işareti simgesini belirler.
Kullanılan: none
Varsayılan: disc
overflow-x: auto
Yatay taşma olduğunda kaydırma çubuğu gösterir.
Kullanılan: auto
Varsayılan: visible
table-auto
Tablo sütun genişliklerini içeriğe göre otomatik hesaplar.
Kullanılan: table-auto
Alternatif: table-fixed
