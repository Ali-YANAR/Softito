Responsive Tasarımın Temelleri

Web dünyasında duyarlı tasarım geliştirmek için kullanılan 4 teknik ve 4 standart kesme noktası

A) Responsive Tasarımın 4 Temel Yolu (Teknikler)

Teknik 01

Esnek Izgaralar (Fluid Grids)

Sabit genişlikler yerine yüzdelik ve dinamik kutu modelleri kullanarak sayfa düzenini esnek hale getirir.

.kapsayici {
  display: grid;
  grid-template-columns: 
    repeat(auto-fit, minmax(250px, 1fr));
}
Teknik 02

Medya Sorguları (Media Queries)

CSS'in tarayıcı veya cihaz özelliklerini inceleyerek sadece hedeflenen ekrana göre kod çalıştırmasını sağlar.

@media (max-width: 768px) {
  .nav-menu {
    display: block; /* Dikey hizalama */
  }
}
Teknik 03

Esnek Görseller (Fluid Images)

Görsellerin ve videoların ekran boyutunu aşarak taşmasını veya kalitesinin bozulmasını engeller.

img, video {
  max-width: 100%;
  height: auto;
}
Teknik 04

Esnek Tipografi (Typography)

Metin boyutlarının sabit kalmayıp ekran büyüklüğüne göre otomatik ölçeklenmesini sağlar.

h1 {
  font-size: clamp(1.5rem, 4vw, 3rem);
}

B) Standart Kabul Edilen 4 Cihaz Ölçüsü (Breakpoints)

Boyut 01

Mobil Ekranlar

Akıllı telefonlar için kullanılan ve genellikle dikey yönü hedefleyen en küçük ekran aralığıdır.

/* 0px - 767px arası cihazlar */
@media (max-width: 767px) {
  body { font-size: 14px; }
}
Boyut 02

Tablet Ekranlar

Büyük ekranlı telefonlar ile standart tablet boyutlarını kapsayan geçiş aşamasıdır.

/* 768px - 991px arası cihazlar */
@media (min-width: 768px) {
  .kolon { width: 50%; }
}
Boyut 03

Masaüstü / Laptop

Standart dizüstü bilgisayarlar ve küçük monitörler için uygulanan yerleşim planıdır.

/* 992px - 1199px arası cihazlar */
@media (min-width: 992px) {
  .kolon { width: 33.3%; }
}
Boyut 04

Geniş Ekranlar

Büyük masaüstü monitörler ve yüksek çözünürlüklü televizyon panelleri için geçerlidir.

/* 1200px ve üzeri cihazlar */
@media (min-width: 1200px) {
  .kapsayici { max-width: 1140px; }
}
